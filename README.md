# Unemployment Analysis with Python

## Objective
Analyze unemployment trends in India using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis
- State-wise Analysis
- Covid-19 Impact Analysis
- Data Visualization

## Key Findings
1. Unemployment increased during Covid-19.
2. Some states showed higher unemployment rates than others.
3. Monthly unemployment trends fluctuated significantly.
4. Data visualization helped identify patterns and trends.
